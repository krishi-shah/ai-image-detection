## Project Summary

AI-generated images have become increasingly difficult to distinguish from authentic photographs. Detection tools exist, but they are predominantly trained and evaluated on datasets of images generated by older generative models. As newer architectures such as Stable Diffusion 3, Midjourney v6, and GPT-4o produce increasingly realistic outputs, a critical question emerges: **do existing detectors still work, and if not, why?**

This project investigates the **generalisation gap** in AI-generated image detection -- the degree to which a detector trained on one generation of synthetic images degrades when tested against images produced by newer, more capable models. By fine-tuning an EfficientNet-B3 classifier on the CIFAKE benchmark and systematically evaluating it against five generator families, this project quantifies the performance gap and uses Grad-CAM visualisations, frequency analysis, and calibration metrics to identify what features the detector learned and why they fail to transfer.

## Research Question

> How well do AI-generated image detectors trained on current benchmark datasets generalise to images produced by next-generation generative models, and what accounts for the performance gap?

| Learned Temperature | 1.2189 | -- |

### Per-Class Performance (CIFAKE Test Set)

| Class | Precision | Recall | F1-Score | Support |
|---|---|---|---|---|
| FAKE (class 0) | 98.58% | 95.29% | 96.91% | 10,000 |
| REAL (class 1) | 95.44% | 98.63% | 97.01% | 10,000 |

### Key Findings

- The detector achieves near-perfect accuracy on CIFAKE but shows significant degradation on images from newer generators, confirming the generalisation gap hypothesis
- Grad-CAM analysis reveals the model relies on **Stable Diffusion v1.4-specific texture artifacts** that newer generators no longer produce
- GPT-4o images are the hardest to detect -- frequency analysis shows their power spectra closely match real images, and t-SNE embeddings place them in the real-image cluster
- Temperature scaling confirms the model becomes **miscalibrated under distribution shift** -- confidence scores no longer match true accuracy when tested on out-of-distribution generators

### Milestone 2: Baseline Detector and Calibration (May 21 -- June 15)

Fine-tuned an EfficientNet-B3 on CIFAKE and implemented post-hoc temperature scaling for confidence calibration.

**Notebooks:** `02_baseline_training.ipynb`, `03_calibration.ipynb`

**Model architecture:**

```
EfficientNet-B3 (ImageNet pretrained, via timm)
  └─ classifier: Linear(1536, 2)   # [FAKE, REAL]
```

**Training configuration:**

| Parameter | Value |
|---|---|
| Optimizer | AdamW |
| Scheduler | CosineAnnealingLR (T_max=20) |
| Loss | CrossEntropyLoss |
| Batch size | 32 |
| Epochs | 20 (full training), 3 (sweep) |
| Hyperparameter sweep | 2 learning rates x 3 weight decays |
| Random seed | 42 |

**Preprocessing:**
- Train: Resize(224), RandomHorizontalFlip, RandomCrop(224, pad=8), ColorJitter, ImageNet Normalize
- Val/Test: Resize(256), CenterCrop(224), ImageNet Normalize

**Calibration:** Temperature scaling learned via L-BFGS on the validation set (Guo et al., 2017). Learned T=1.2189, indicating the model was slightly overconfident. The model's pre-calibration ECE was already remarkably low (0.0026), so temperature scaling slightly increased ECE to 0.0113 -- a known edge case when the model is already well-calibrated.

**Results:**

| Metric | Value |
|---|---|
| Test Accuracy | **96.96%** |
| AUC-ROC | **0.9971** |
| ECE (pre-calibration) | 0.0026 |
| Temperature | 1.2189 |

**Label convention:** `0 = FAKE`, `1 = REAL` (CIFAKE ImageFolder alphabetical order).

**Source modules:**
- [`src/model/detector.py`](src/model/detector.py) -- model build, checkpoint save/load
- [`src/evaluation/calibration.py`](src/evaluation/calibration.py) -- temperature scaling

### Milestone 3: Grad-CAM Explainability (June 16 -- July 5)

Integrated Grad-CAM into the model pipeline to understand what image regions drive classification decisions.

**Notebook:** `04_gradcam.ipynb`

**Key findings:**
- **REAL images:** Broad, diffuse attention across fine-grained texture regions. Uniformly high confidence (99-100%).
- **FAKE images:** More localised attention on regions with visible generation artifacts. Lower-confidence predictions show scattered activation, indicating uncertainty about which regions contain artifacts.
- The model relies on **low-level texture artifacts specific to Stable Diffusion v1.4**, directly supporting the generalisation gap hypothesis.

**Implementation:** Uses `pytorch-grad-cam` library targeting `model.conv_head` (last convolutional layer of EfficientNet-B3).

**Source module:** [`src/explainability/gradcam.py`](src/explainability/gradcam.py) -- `run_gradcam()`, `save_heatmap()`, `batch_gradcam_failures()`, `comparative_grid()`

#### GPT-4o Deep-Dive (Notebook 06)

Investigated why GPT-4o images are hardest to detect:

- **FFT radial power spectra:** GPT-4o images have frequency signatures nearly identical to real photos, unlike GAN images which show distinct spectral peaks (Corvi et al., 2023)
- **t-SNE embeddings:** GPT-4o images cluster with CIFAKE real images in the 1536-dimensional feature space, making them nearly indistinguishable at the representation level
- **Quantitative Grad-CAM metrics:** Entropy, peak activation ratio, and Gini coefficient show diffuse, unfocused attention on GPT-4o images -- the model has no clear signal to detect

**Analysis modules:**
- [`src/analysis/frequency.py`](src/analysis/frequency.py) -- FFT radial power spectra

## Evaluation Metrics

- **Accuracy** -- overall classification accuracy on balanced test sets
- **AUC-ROC** -- area under the receiver operating characteristic curve; threshold-independent
- **ECE (Expected Calibration Error)** -- measures how well confidence scores match true accuracy; lower is better
- **Reliability Diagrams** -- visual calibration quality; perfect calibration lies on the diagonal
- **Fake Detection Rate** -- recall on FAKE images specifically (most relevant for deployment)
